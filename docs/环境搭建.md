# 环境搭建与启动（组员用）

从零到跑起来，按顺序做。全程大概 40 分钟，主要时间花在下载。

## 一、装软件

**1. Git**
官网下 Windows 版，一路下一步。装完在命令行敲 `git --version` 有版本号就行。

**2. Android Studio**
官网下最新稳定版安装。安装向导里会问 SDK 装在哪，用默认的
`C:\Users\你的用户名\AppData\Local\Android\Sdk` 就行，记下这个路径。

**3. JDK 不用单独装**
Android Studio 自带 JetBrains Runtime 21，后面把 Gradle 的 JDK 指到它就行。

## 二、配 Git 身份

命令行执行，名字写自己的，不然提交记录看不出是谁：

```bash
git config --global user.name "张三"
git config --global user.email "你的邮箱"
```

## 三、拉代码

```bash
cd /d D:\
git clone https://github.com/kamten7/Notes-master.git
```

放在没有中文和空格的路径下，比如 `D:\Notes-master`。

## 四、用 Android Studio 打开

1. File → Open → 选克隆下来的 `Notes-master` 目录，**不要选它的上一级**；
2. 弹窗问你信任项目，点 Trust；
3. 等右下角 Gradle Sync 跑完。第一次要下 AGP 和依赖，几百 MB，
   工程里已经配了阿里云和腾讯的镜像，正常十几分钟能完。

### 可能要手动的两处设置

**Gradle JDK**：Settings（Ctrl+Alt+S）→ Build, Execution, Deployment → Build Tools → Gradle
→ Gradle JVM 选 `jbr-21`（JetBrains Runtime）或本机装的 JDK 21。

**Android SDK**：Settings → Languages & Frameworks → Android SDK，
SDK 路径指向上面记的那个目录，勾选 **Android API 35**（没有就点右下角 Apply 让它下）。

## 五、建模拟器

Tools → Device Manager → Create Virtual Device → 选 Pixel 6 → 系统镜像选
**API 35（或更高）的 x86_64**，下载完 → Finish。

没有镜像的话在 Device Manager 里点下载图标，选一个 Google APIs 的 x86_64 版本。

## 六、运行

顶部工具栏：左边选 `app`，右边选刚建的模拟器，点绿色三角。
第一次编译 1 分钟左右，模拟器上出现便签列表就算成功。

验证是最新代码：打开便签 → 点右上角的 `⋮` → 应该看到 `Lock note` 和 `Tags` 两项。

## 七、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `src` 是灰色、Java 文件标红 | Gradle 没同步成功 | 点右上角大象图标重新 Sync，看底部 Build 窗口的报错 |
| 弹窗要装 `Sources for Android 35` 卡住 | 在从 Google 下载框架源码 | 点 Cancel，不影响编译运行 |
| Sync 卡在下载依赖 | 网络问题 | 确认 `settings.gradle` 里的阿里云镜像还在，别删 |
| Run 按钮是灰的 | 没有设备或同步没完成 | 先启动模拟器，再确认 Sync 成功 |
| 编译报 `setLatestEventInfo` 找不到 | 用了很老的源码 | 当前仓库已修，确认拉的是最新代码 |
| 提示 minSdk 14 相关的警告 | 正常现象 | 课程实验固定 targetSdk 28，不用管 |

## 八、提交前

```bash
git status
git diff
git add 具体文件
git commit -m "feat: 简短说明做了什么"
```

编译过了再提交。分支和合并规则见 `docs/协作说明.md`。
