## 四、两个缺陷的具体说明

1. **空条件删除**
   `delete()` 里无条件执行 `selection = "(" + selection + ") AND _id>0"`，
   调用方传 `null` 时得到 `(null) AND _id>0`，SQLite 把 `null` 当标识符，
   语句不成立，删除影响 0 行。
   修复：仅在 `selection` 非空时拼接，空条件时只保留 `_id>0`。

2. **参数被当成 SQL 文本**
   `increaseNoteVersion()` 用 `replaceFirst("\\?", args)` 把参数直接替换进 SQL 字符串。
   参数含单引号或 `OR 1=1` 时等于把用户输入拼进 SQL；参数数组为空时还会空指针。
   修复：条件片段用 `?` 占位，参数放进 `execSQL(sql, Object[])` 的绑定数组。
